# Textos de divulgação

## GitHub

O Viral Cutter Classic transforma podcasts e entrevistas longas em clipes verticais 9:16 usando processamento local, detecção de participantes, enquadramento seguro, legendas e retomada após interrupções. O projeto está aberto a colaboradores por Issues e Pull Requests.

## LinkedIn

Estamos desenvolvendo o Viral Cutter Classic, um editor local para transformar vídeos longos em cortes verticais para Shorts, Reels e TikTok. O foco é preservar pessoas no enquadramento, facilitar a produção de podcasts e manter o processamento sob controle do usuário. Colaborações são bem-vindas no GitHub.

## Discord

Projeto aberto para quem gosta de vídeo, FFmpeg, visão computacional e ferramentas locais: o Viral Cutter Classic detecta participantes, cria cortes 9:16 e tenta manter todos bem enquadrados. Bugs, testes e ideias são bem-vindos.

## Chamada curta

Ajude a construir um editor local que transforma podcasts longos em cortes verticais sem perder as pessoas no enquadramento.
