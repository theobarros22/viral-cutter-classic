# Como contribuir

Obrigado por ajudar no Viral Cutter Classic.

## Fluxo

1. Abra uma Issue descrevendo o problema ou a proposta.
2. Crie uma branch a partir de `develop`.
3. Faça uma alteração pequena e bem documentada.
4. Execute `python -m unittest discover -s tests`.
5. Abra um Pull Request para `develop`.
6. Aguarde a revisão e a validação automática.

## Regras

- Não envie vídeos, credenciais, chaves de API, ambientes virtuais ou dados pessoais.
- Não altere o enquadramento sem adicionar ou atualizar testes.
- Explique como reproduzir qualquer bug.
- Inclua evidência de teste no Pull Request.
- Alterações em `main` somente por Pull Request aprovado.
